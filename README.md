# Snake-Water-Gun-Game

## About the Project
This is a simple Python game based on Snake, Water and Gun.

## Technologies Used
- Python

## Game Rules
- Snake drinks Water.
- Water damages Gun.
- Gun kills Snake.

## How to Run
1. Download or clone this repository.
2. Open the project in Python or VS Code.
3. Run `Project_1.py`.
4. Enjoy the game!
